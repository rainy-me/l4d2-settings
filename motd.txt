[ 개요 ]
- 바닐라 게임 플레이 유지
- 세밀한 성능 튜닝으로 쾌적한 서버
- 버그 수정 및 억까 방지
- 낭비되는 시간 절약

[ 기능 ]
- 핑 찍기        → 보컬라이저 'Look'
- 아이템 전달    → 밀치기 또는 R키
- 아이템 던지기  → !throw
- 자살           → !kill
- 현재 진행도    → !p
- 길 안내        → !ptg
- 하드모드 확인  → !hard
- 탄약 배수 확인 → !amm
- MVP 확인       → !mvp, !mvpme

[ 서버 로직 ]
- 챕터 진행 중 접속 시 자동 리스폰
- 봇 생존자 자동 킬
- AWP & Scout 데미지 상향
- 공식맵 막챕 기름통 모으기 제거
