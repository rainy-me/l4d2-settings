# L4D2 Settings

Rainy의 Left 4 Dead 2 설정 모음입니다.

## 1. 설정 파일 적용 방법

> 주의: 저의 게임 환경과 똑같이 설정할 사람만 실행하세요.

`설정_적용.cmd`를 실행하면 자동으로 설정 파일이 적용됩니다.

- 게임 경로는 Steam 라이브러리에서 자동으로 찾습니다.
- 자동으로 찾지 못하면 `left4dead2.exe`가 있는 폴더 경로를 직접 입력하세요.

## 2. 실행 옵션 설정 방법

Steam 라이브러리에서 Left 4 Dead 2를 우클릭 → 속성 → 일반 → 실행 옵션에 `실행 옵션.txt` 내용을 복붙합니다.

주의: 공방에 접속하려면 `-insecure`를 `--insecure`로 변경합니다.
